# NewbornCare India Website

A mobile-first static HTML/CSS/JS website for a newborn baby-care information and digital-product business.

## Files
- `index.html` — website
- `style.css` — design and responsive layout
- `script.js` — menu and small interactions
- `Newborn_Care_Checklist.pdf` — downloadable checklist

## Before publishing
1. Replace the demo contact form with your Google Form or form provider.
2. Connect the paid-product buttons to your payment/delivery platform.
3. Replace the product placeholders with your approved affiliate URLs.
4. Add your own Privacy Policy and Terms pages.
5. Review medical content with an appropriate qualified professional before commercial publication.
6. Add your final logo, domain and contact details.

## GitHub Pages
Create a GitHub repository, upload these files to the repository root, then enable:
Settings → Pages → Deploy from branch → main → / (root)
